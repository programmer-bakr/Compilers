الفصل الأول: Introduction

1. Programming Languages
Definition: A programming language is a set of symbols, words, and rules used to instruct the computer.
لغة البرمجة هي مجموعة من الرموز والكلمات والقواعد المستخدمة لإعطاء التعليمات للحاسوب.
2. Types of Programming Languages حفظ الأنواع الأربعة
  1. Machine Language: The actual language in which the computer carries out instructions.
    لغة الآلة، تعتمد على الأكواد الرقمية (Numeric Code).
  2. Assembly Language: A symbolic version of machine language.
    لغة رمزية تستخدم اختصارات مثل ADD و SUB.
  3. High-Level Language (H.L.L): A language that does not require knowledge of the actual computing machine.
    لغة عالية المستوى لا تتطلب معرفة تفاصيل الجهاز.
  4. Problem-Oriented Language: Provides expression of problems in a specific application.
    لغة مخصصة لتطبيق معين، مثل SQL لقواعد البيانات.
3. Advantages of H.L.L over L.L.L مهم جداً – تعداد (6)
  • H.L.L are easier to learn than L.L.L.
  • No need to know how to convert data from external to internal form.
  • Offers a variety of control structures.
  • Programs are more easily debugged.
  • Offers more powerful data structures.
  • Relatively machine-independent and portable.
4. Translator & Types احفظ الجدول
Definition: A translator converts a source program into an object or target program.
المترجم يحول البرنامج المصدري إلى برنامج هدف.

5. Compile Time vs Run Time
  • Compile Time: The time at which the source program is converted into an object program. (وقت الترجمة)
  • Run Time: The time at which the object program is executed. (وقت تنفيذ البرنامج)
6. Interpreter & Compiler vs Interpreter
Definition: An interpreter processes the source program and data at the same time.
المفسر يعالج البرنامج والبيانات في الوقت نفسه، ولا ينتج Object Program.

الفصل الثاني: Compilation Concepts

7. What is Compiler? & Model of Compiler
Definition: A compiler is a program that translates a source program written in H.L.L into an equivalent target program written in L.L.L.
المترجم برنامج يحول لغة عالية المستوى إلى لغة منخفضة المستوى.

مهمتا المترجم الأساسيتان (Model of Compiler):

  1. Analysis: Decomposition of the source program into its basic parts. (تحليل البرنامج وتقسيمه إلى أجزاء أساسية)
  2. Synthesis: Builds the equivalent object program using these basic parts. (بناء البرنامج الهدف باستخدام الأجزاء الأساسية)

6. Code Generation
  1. Lexical Analyzer: Separates source code into tokens. (تقسيم الكود إلى Tokens مثل Keywords و Variables و Operators).
  2. Syntax Analyzer: Combines tokens into well-formed expressions and statements. (يجمع الرموز ويتحقق من صحة تركيب الجمل).
  3. Semantic Analyzer: Determines the meaning of the source program. (يتحقق من المعنى الصحيح للبرنامج).
  4. Intermediate Code Generator: Creates an internal form of the program. (ينشئ كوداً وسيطاً).
  5. Code Optimizer: Produces a more efficient object program. (يجعل البرنامج أسرع أو يقلل المساحة أو الاثنين معاً).
  6. Code Generator: Translates intermediate representation into target language. (يحول الكود الوسيط إلى لغة الهدف).

10. Symbol Table (جدول الرموز)
Definition: A symbol table is a data structure containing a record for each identifier, with fields for the attributes of the identifier.
جدول الرموز هو هيكل بيانات يحتوي على سجل لكل Identifier وخصائصه.

Symbol Table Contents (الخصائص السبعة):

  • Variable Name.
  • Object Time Address.
  • Type.
  • Dimension of Array or Number of Parameters.
  • Source Line Number at which the variable is declared.
  • Source Line Number at which the variable is referenced.
  • Link Field for alphabetical order.

Operations on Symbol Table:

  • Insertion: إضافة عنصر.
  • Lookup (Retrieval): البحث واسترجاع المعلومات.
  • Set: إنشاء جدول فرعي عند بداية Block.
  • Reset: إزالة الجدول الفرعي عند نهاية Block.

ST Organizations:

  • Unordered ST: إضافة المتغيرات حسب ترتيب التصريح بها.
  • Ordered ST: ترتيب المتغيرات حسب أسمائها.
  • Tree-Structured ST: تنظيم جدول الرموز باستخدام Tree.

الفصل الثالث: Errors

11. Types of Errors تعريفات وفروقات
  1. Lexical Errors: Errors where the input characters do not form any token of the language.
    خطأ يحدث عندما لا تشكل الأحرف Token صحيحاً.
  2. Syntax Errors: Errors where the token stream violates the structure rules of the language.
    خطأ في تركيب الجملة أو قواعد اللغة (مثال: عدم توازن الأقواس).
  3. Semantic Errors: Errors where the program has the right syntactic structure but has no correct meaning.
    التركيب صحيح لكن المعنى غير صحيح (مثال: إجراء عملية غير مناسبة بين Array و Procedure).
12. Compile-Time vs Runtime Errors

Compile-Time Errors: الأخطاء التي يكتشفها المترجم أثناء الترجمة، وغالباً تحتوي رسالتها على: File Name، Line Number، Type of Error.

Runtime Errors: Occur while the program is running, although compilation is successful.
أخطاء تحدث أثناء تنفيذ البرنامج رغم نجاح الترجمة.

A. External Factors

  • Out of memory.
  • Hard disk full.
  • Insufficient I/O privileges.

B. Internal Factors

  • Arithmetic errors.
  • Read beyond the end of a file.
  • Open a non-existent file.
  • Read beyond the end of an array.

الفصل الخامس: Lexical Analyzer

14. Lexical Analyzer (Scanner) & Tokens
Definition: The lexical analyzer or scanner reads the source program one character at a time and produces a stream of tokens.
يقوم بقراءة البرنامج حرفاً حرفاً وإنتاج مجموعة من Tokens.
TokenExampleRepresentation <class, value>
Identifierssum, value, X<ident, "sum">
Numeric Literals123, 1.35E02<numericliteral, "123">
Operators+, *, &&, >=<relop, ">="> , <addop, "+">
Keywordsif, else, return<keyword, "if">

Interaction of Scanner with Parser:

  • يمسح البرنامج في Pass منفصل ويخزن الـ Tokens في ملف أو جدول.
  • يُستدعى Scanner بواسطة Parser كلما احتاج إلى Token جديد (الطريقة المفضلة حسب المحاضرة).

Secondary Tasks: Removing Comments, White Spaces, Blank, Tab, New Line Characters.

Lexical Error Recovery Actions (احفظ التعداد الأربعة):

  1. Deleting an extraneous character.
  2. Inserting a missing character.
  3. Replacing an incorrect character.
  4. Transposing two adjacent characters.

الفصل السابع: Ambiguity & Grammar Transformation

17. Ambiguity & Elimination مهم جداً
Definition: A grammar that produces more than one parse tree for the same sentence is said to be ambiguous.
القواعد تكون غامضة إذا أنتجت أكثر من Parse Tree (أو أكثر من Left-Most / Right-Most Derivation) للجملة نفسها، مثل: id + id * id.

إعادة كتابة القواعد لإزالة الغموض (Elimination of Ambiguity):

E → E + T | T
E → (E)
E → -E
T → T * F | F
F → id
18. Left-Recursion & Elimination
Definition: A grammar is left-recursive if there is a nonterminal A such that: A → Aα (Top-Down Parser cannot handle it).
القاعدة العامة للتحويل: إذا كانت A → Aα | β تصبح A → βA' و A' → αA' | ε

قبل التحويل (Before)

E → E + T | T
T → T * F | F
F → (E) | id

بعد التحويل (After)

E  → T E'
E' → +T E' | ε

T  → F T'
T' → *F T' | ε

F  → (E) | id
19. Left-Factoring (صفحة 25)
Definition: Left-Factoring is used when it is not clear which alternative production to use to expand a nonterminal.
القاعدة العامة: إذا كانت A → αβ₁ | αβ₂ تصبح A → αA' و A' → β₁ | β₂

قبل التحويل (Before)

S → iEtS | iEtSeS | a
E → b

بعد التحويل (After)

S  → iEtSS' | a
S' → eS | ε
E  → b
