الفصل الأول: Introduction

Programming Languages
A programming language is a set of symbols, words, and rules used to instruct the computer.
لغة البرمجة مجموعة من الرموز والكلمات والقواعد المستخدمة لإعطاء التعليمات للحاسوب.
Types of Programming Languages احفظ الأنواع
  1. Machine Language: The actual language in which the computer carries out instructions. — لغة الآلة.
  2. Assembly Language: A symbolic version of machine language. — لغة رمزية مثل ADD وSUB.
  3. High-Level Language (H.L.L): Does not require knowledge of the actual computing machine. — لغة عالية المستوى.
  4. Problem-Oriented Language: Expresses problems in a specific application. — مثل SQL.
Advantages of H.L.L over L.L.L 6 نقاط
  1. H.L.L are easier to learn than L.L.L.
  2. No need to know how to convert data from external to internal form.
  3. Offers a variety of control structures.
  4. Programs are more easily debugged.
  5. Offers more powerful data structures.
  6. Relatively machine-independent and portable.
Translator & Types
A translator converts a source program into an object or target program.
المترجم يحول البرنامج المصدري إلى برنامج هدف.
TypeSourceTarget
AssemblerAssemblyMachine
CompilerH.L.LL.L.L
DecompilerL.L.LH.L.L
Compile Time vs Run Time
  • Compile Time: The time at which the source program is converted into an object program. (وقت الترجمة)
  • Run Time: The time at which the object program is executed. (وقت التنفيذ)
Interpreter vs Compiler
An interpreter processes the source program and data at the same time.
المفسر يعالج البرنامج والبيانات في الوقت نفسه ولا ينتج Object Program.
CompilerInterpreter
Generates object programNo object program

الفصل الثاني: Compilation Concepts

Compiler & Model of Compiler
A compiler translates a source program written in H.L.L into an equivalent target program written in L.L.L.
المترجم يحول لغة عالية المستوى إلى لغة منخفضة المستوى.
  1. Analysis: Decomposition of the source program into its basic parts. (تحليل وتقسيم البرنامج)
  2. Synthesis: Builds the equivalent object program using these basic parts. (بناء البرنامج الهدف)
Compiler Phases بالترتيب
Lexical Analyzer ← Syntax Analyzer ← Semantic Analyzer ← Intermediate Code ← Code Optimization ← Code Generation
  1. Lexical Analyzer: Separates source code into tokens.
  2. Syntax Analyzer: Combines tokens into well-formed expressions and statements.
  3. Semantic Analyzer: Determines the meaning of the source program.
  4. Intermediate Code Generator: Creates an internal form of the program.
  5. Code Optimizer: Produces a more efficient object program.
  6. Code Generator: Translates intermediate representation into target language.

Symbol Table
A data structure containing a record for each identifier, with fields for the attributes of the identifier.
هيكل بيانات يحتوي على سجل لكل Identifier وخصائصه.

Contents:

  1. Variable Name.
  2. Object Time Address.
  3. Type.
  4. Dimension of Array or Number of Parameters.
  5. Source Line Number at which the variable is declared.
  6. Source Line Number at which the variable is referenced.
  7. Link Field for alphabetical order.

Operations: Insertion (إضافة)، Lookup/Retrieval (بحث واسترجاع)، Set (إنشاء جدول فرعي عند بداية Block)، Reset (إزالة الجدول الفرعي عند نهاية Block).

Organizations: Unordered ST، Ordered ST، Tree-Structured ST.

الفصل الثالث: Errors

Types of Errors تعريفات
  1. Lexical Errors: Input characters do not form any token of the language. — الأحرف لا تكوّن Token صحيحاً.
  2. Syntax Errors: Token stream violates the structure rules of the language. — خطأ في تركيب الجملة.
  3. Semantic Errors: Program has correct syntactic structure but incorrect meaning. — التركيب صحيح لكن المعنى غير صحيح.
Compile-Time vs Runtime Errors

Compile-Time Errors: أخطاء يكتشفها المترجم أثناء الترجمة، وقد تتضمن File Name وLine Number وType of Error.

Runtime Errors occur while the program is running, although compilation is successful.
أخطاء تحدث أثناء التنفيذ رغم نجاح الترجمة.

External Factors

  • Out of memory.
  • Hard disk full.
  • Insufficient I/O privileges.

Internal Factors

  • Arithmetic errors.
  • Read beyond end of file.
  • Open a non-existent file.
  • Read beyond end of array.

الفصل الرابع: Language Processing System

Processing Stages, Preprocessing & Loader
Source Program ← Preprocessor ← Compiler ← Assembler ← Link Editor / Loader ← Machine Code

Preprocessing:

  • Comments: Removed from source file.
  • Macros: Replaced with equivalent text. Example: #define pi 3.14
  • Directives: Processed by the preprocessor.

Loader / Link Editor:

  • Loading: Places machine code and data in memory at proper locations.
  • Link-Editing: Makes a single program from several files.

الفصل الخامس: Lexical Analyzer

Lexical Analyzer (Scanner) & Tokens
The lexical analyzer or scanner reads the source program one character at a time and produces a stream of tokens.
يقرأ البرنامج حرفاً حرفاً وينتج مجموعة من Tokens.
TokenExampleRepresentation
Identifierssum, value, X<ident, "sum">
Numeric Literals123, 1.35E02<numericliteral, "123">
Operators+, *, &&, >=<relop, ">=">
Keywordsif, else, return<keyword, "if">

Scanner with Parser:

  • Separate pass: scanner processes source and stores tokens in a file or table.
  • On-demand: parser calls scanner whenever it needs a new token (الطريقة المفضلة في الملخص).

Secondary Tasks: Removing Comments, White Spaces, Blank, Tab, New Line Characters.

Lexical Error Recovery Actions:

  1. Deleting an extraneous character.
  2. Inserting a missing character.
  3. Replacing an incorrect character.
  4. Transposing two adjacent characters.

الفصل السابع: Ambiguity & Grammar Transformation

Ambiguity & Elimination مهم جداً
A grammar that produces more than one parse tree for the same sentence is said to be ambiguous.
القواعد غامضة إذا أنتجت أكثر من Parse Tree للجملة نفسها، مثل id + id * id.

Elimination of Ambiguity:

E → E + T | T
E → (E)
E → -E
T → T * F | F
F → id
Left-Recursion & Elimination
A grammar is left-recursive if there is a nonterminal A such that A → Aα. Top-Down Parser cannot handle it.
إذا كانت A → Aα | β تصبح A → βA' و A' → αA' | ε.

Before

E → E + T | T
T → T * F | F
F → (E) | id

After

E  → T E'
E' → +T E' | ε
T  → F T'
T' → *F T' | ε
F  → (E) | id
Left-Factoring
Left-Factoring is used when it is not clear which alternative production to use to expand a nonterminal.
إذا A → αβ₁ | αβ₂ تصبح A → αA' و A' → β₁ | β₂.

Before

S → iEtS | iEtSeS | a
E → b

After

S  → iEtSS' | a
S' → eS | ε
E  → b

Q1: Fill in the Blanks 5 Marks
1. ______ and ______ phases usually handle a large fraction of the errors detectable by the compiler.
Lexical Analysis and Syntax Analysis.

التحليل اللفظي والتحليل النحوي يكتشفان نسبة كبيرة من أخطاء البرنامج.

2. ______ is the actual language in which the computer carries out instructions.
Machine Language.

لغة الآلة هي اللغة الفعلية التي ينفذ بها الحاسوب التعليمات.

3. ______ processes an internal form of source program and data at the same time.
Interpreter.

المفسر يعالج البرنامج والبيانات في الوقت نفسه.

4. If source language is L.L.L and object language is H.L.L, the translator is called ______.
Decompiler.

المترجم العكسي يحول من لغة منخفضة المستوى إلى لغة عالية المستوى.

5. A compiler must perform two major tasks: ______ and ______.
Analysis and Synthesis.
6. The ______ can detect errors where the characters remaining in the input do not form any token of the language.
Lexical Analyzer (Scanner).
7. If ST is ______, insertion operation may also involve a lookup operation.
Ordered Symbol Table.

لأن الإدراج يحتاج تحديد موقع المتغير وفق الترتيب.

8. A grammar that produces more than one parse tree for the same sentence is said to be ______.
Ambiguous Grammar.
Q2: Respond to the Following 5 Marks
1. What is the hierarchy of programming languages based on increasing machine independence?
1. Machine Language
2. Assembly Language
3. High-Level Language
4. Problem-Oriented Language

كلما ارتفع مستوى اللغة زادت استقلاليتها عن نوع الجهاز.

2. Explain the programs required in addition to a compiler to create an executable target program.
1. Preprocessor:
   Processes directives, removes comments
   and expands macros.

2. Assembler:
   Converts assembly language into machine code.

3. Link Editor:
   Combines object files and libraries
   into one executable program.

4. Loader:
   Loads the executable program into memory.

هذه البرامج تكمل مراحل إعداد البرنامج التنفيذي بعد كتابة البرنامج المصدري.

3. The scanner usually interacts with the parser in one of two ways. Explain.
1. Separate Pass:
   Scanner processes the source program
   and stores tokens in a file or table.

2. On-Demand:
   Parser calls the scanner whenever
   it needs the next token.

في الطريقة الثانية يطلب Parser الرمز التالي عند الحاجة إليه.

4. What are the contents of Symbol Table?
1. Variable Name.
2. Object Time Address.
3. Type.
4. Dimension of Array or Number of Parameters.
5. Source Line Number at which variable is declared.
6. Source Line Number at which variable is referenced.
7. Link Field for alphabetical order.
5. In block-structured languages, how does the compiler designer resolve the duplicated variable-name problem?
Using a separate Symbol Table for each block.

Set:
Create a new symbol table when entering a block.

Lookup:
Search the current block first, then enclosing blocks.

Reset:
Remove the local symbol table when leaving the block.

يُستخدم Scope منفصل لكل Block؛ لذلك يمكن تكرار اسم المتغير في Blocks مختلفة، ويُبحث أولاً في النطاق المحلي ثم النطاقات الخارجية.

Q3: Grammar and Nonrecursive Predictive Parsing 5 Marks
Consider the following grammar:
S → (W) | x | S;
W → S,S | S
1. Is the above grammar LL(1) or not?
Answer: NO, it is not LL(1).

Reasons:

  1. There is direct left recursion in S → S;.
  2. W → S,S | S has alternatives with a common prefix S.

لذلك لا يمكن استخدام محلل LL(1) التنبؤي القياسي مباشرة قبل إزالة Left Recursion وLeft Factoring عند الحاجة.

2. Is the statement (x) accepted?
Input: (x)

Derivation:
1. S → (W)
2.   → (S)
3.   → (x)

Result: ACCEPTED.

السلسلة (x) مقبولة حسب القواعد؛ لأننا اشتققناها من S → (W)، ثم W → S، ثم S → x.

ملاحظة: قبول السلسلة حسب القواعد لا يعني أن القواعد LL(1). كما أن وجود Left Recursion يمنع تطبيق Nonrecursive Predictive Parsing القياسي مباشرة على القواعد بصيغتها الحالية.
